# Evidence nộp bài

Mở các đầu mục theo thứ tự:

1. 01-readme: README chạy lại toàn bộ, gồm lệnh proto.
2. 02-plan: các quyết định đã chốt trước khi hiện thực gRPC.
3. 03-api-snapshots: status và body API ngoài trước/sau, đủ hàng/thiếu hàng.
4. 04-internal-logs: log lời gọi nội bộ REST và gRPC.
5. 05-proto-diff: proto trước/sau và output kiểm tra/sinh code.
6. 06-client-compatibility: client cũ, client mới, version và kết quả chạy.
7. 07-failure-handling: thiếu hàng, Inventory chậm và Inventory tắt.
8. 08-payload: bảng kích thước payload và cách đo.
9. 09-developer-experience: ghi chú trải nghiệm phát triển.
10. 10-tradeoffs: trade-off và giới hạn phép đo.

Các file trong evidence được tổ chức theo đầu mục nộp, không dùng tên part.
